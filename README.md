# Ozon Goods Bot

Бот для продавца Ozon: мониторинг цен, остатков FBO/FBS, возвратов, отзывов, заказов и доставок (Ozon, Яндекс Доставка, СДЭК).

## Возможности

- синхронизация товаров из Ozon Seller API;
- отслеживание цен и уведомление об изменениях;
- мониторинг остатков FBO/FBS с учётом резервов;
- возвраты, отзывы, заказы за период;
- доставки по нескольким перевозчикам;
- предупреждения о прибытии в ПВЗ и истечении срока хранения;
- ежедневный отчёт;
- настройки и inline-навигация в Telegram.

## Требования

- Python 3.11+
- PostgreSQL/БД не требуется, состояние хранится в JSON;
- доступ к Ozon Seller API;
- для доставок: токены Яндекс Доставки и/или СДЭК (необязательно).

## Установка

1. Клонировать репозиторий.
2. Создать виртуальное окружение и установить зависимости:

```bash
python -m venv venv
pip install -r requirements.txt
```

3. Скопировать `.env.example` в `.env` и заполнить токены.

   Приложение не содержит секретов; все ключи только через `.env`.

4. Запустить:

```bash
python bot.py
```

## Основные переменные окружения

См. `.env.example`.

- `TELEGRAM_BOT_TOKEN`
- `OZON_CLIENT_ID`, `OZON_API_KEY`
- `YANDEX_DELIVERY_TOKEN`
- `CDEK_ACCOUNT`, `CDEK_SECURE_PASSWORD`
- `ADMIN_CHAT_ID`

## Команды

См. справку в боте: `/help`.

## Безопасность

В репозитории не должны публиковаться реальные `.env`, базы, кэш и логи. Используйте только `.env.example`.
